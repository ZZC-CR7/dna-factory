参赛作品 · 设计说明

《分子编辑实验室 · DNA 到蛋白质》

设计目标

把发生在纳米尺度的分子过程，做成可以亲手操作的虚拟仿真实验，服务《分子生物学》教学与生命科学科普。

总体方案

以中心法则为主线组织五层学习路径：解旋复制 → 靶向编辑 → 转录剪接 → 翻译折叠 → 蛋白转运；每层提供对应的分子工具，拖放到正确位置即触发分子事件。

技术实现

纯前端零依赖：HTML5 Canvas 2D 自研动画引擎 + CSS + 原生 JavaScript；数据驱动、状态机管理动画流程；WebAudio 合成音效；支持全屏、键盘操作与自动演示。

创新点

① 以诺贝尔奖足迹编排知识点（1978 限制酶 → 1993 RNA 剪接 → 2020 CRISPR-Cas9）；② 拖放式「分子实验」替代被动观看；③ 零门槛跨平台、一个网址随处可开；④ 层间衔接、成就系统与互动记录。

科学依据

DNA 双螺旋（1962 诺奖）、RNA 剪接发现（1993）、CRISPR-Cas9（2020 诺奖）；应用进展：2023 年 Casgevy 获批上市、2024 年诺贝尔化学奖（AlphaFold2 蛋白质结构预测）、2025 年体内编辑进入 III 期临床。

使用说明

点击或拖拽工具进行互动；顶部 ▶ 自动演示全部五层；图形为教学示意，不用于实验操作指导。

演示网址：https://zzc-cr7.github.io/dna-factory/ · 纯静态部署 · 本地可离线运行
