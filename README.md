# 分子编辑实验室 · 从 DNA 到蛋白质

中国大学生工程实践与创新能力大赛 · 虚拟仿真赛项参赛作品。
以中心法则为主线、用 Canvas 动画呈现「DNA → RNA → 蛋白质」五层学习路径的互动演示。

## 在线访问

https://zzc-cr7.github.io/dna-factory/ （纯静态，任何设备的浏览器直接打开）

## 技术栈（零依赖）

- 原生 HTML5 Canvas 2D：全部分子动画与场景（自研绘制，无任何图形库）
- CSS：深色主题、响应式布局（桌面三栏 / 手机单栏）
- 原生 JavaScript（单文件 app.js）：
  - 数据驱动：层级 / 工具 / 结构说明独立成数据表
  - 状态机：驱动步骤动画、镜头特写与流程推进
  - WebAudio 合成音效（无外部音频文件）
  - 自动演示、全屏、键盘快捷键、成就与互动统计（localStorage 存档）

## 功能

- 五层学习路径：DNA 解旋复制 → CRISPR 靶向编辑与调控（Cas9 / 碱基编辑 / 先导编辑 / 表达调控 / 荧光标记）→ 转录与 RNA 剪接 → 翻译与蛋白质折叠 → 细胞内蛋白质转运
- 拖放分子工具触发分子事件；点击任意结构查看说明；一键自动演示五层
- 五枚学习成就 + 互动统计 + 层间衔接解说 + 技术前沿时间线（2020 之后）
- 层末设计与答辩辅助：设计说明、旅程总结页

## 运行方式

- 在线：打开 https://zzc-cr7.github.io/dna-factory/
- 离线：双击「打开演示.bat」（或直接用新版 Edge / Chrome 打开 index.html），无需任何插件与网络

## 目录

- index.html —— 页面结构
- styles.css —— 样式与响应式布局
- app.js —— 全部交互与动画逻辑
