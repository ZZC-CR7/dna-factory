# 分子编辑实验室

这是一个无需安装依赖的本地互动网页原型，用 Canvas 绘制 DNA、分子工具和细胞运输场景。

## 打开方式

在 Windows 上双击 `打开演示.bat`，或直接用新版 Edge / Chrome 打开 `index.html`。网页不需要插件、Unity 或联网服务；顶部的参考动画链接除外。

## 互动方式

- 首页展示动态 DNA 双螺旋和五层学习路径，可从任一层进入。
- 第 1 层进入后 DNA 会自动舒展并放大；把解旋酶、DNA 聚合酶、连接酶拖到复制叉附近，观察半保留复制步骤。
- 第 2 层可拖动 Cas9·向导 RNA 至靶序列，查看 PAM 识别、双链切割、NHEJ / HDR 修复，以及 dCas9 的表达调控和位点标记演示；页面将本层命名为“DNA 靶向编辑与调控”，与第 3 层 RNA 剪接区分。
- 第 3 至第 5 层分别演示转录与 RNA 剪接、翻译、细胞内蛋白质运输。
- 主按钮会连续播放当前层完整流程；拖放分子工具会播放对应步骤的动态特写。画面会平滑移动视野并显示步骤进度。
- 点击画面中的结构或序列碱基，右侧检查器会显示名称和作用。第五层先演示 mRNA 出核，再演示细胞质中合成的信号肽引导蛋白进入分泌通路。

图形为教学示意，未按分子真实尺寸绘制，也不用于实验操作指导。
